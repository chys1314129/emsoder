# 新闻事实核查 (News Fact Check)

系统化核实新闻真实性的工作流。通过多源交叉验证、信源追溯、权威数据比对等方法，给出结构化的可信度评估报告。

---

## 触发条件

当用户提出以下类型请求时使用此 skill：
- 核实一条新闻是否属实
- 验证截图/转发消息的真假
- 判断某条信息是否为谣言
- 对比多家报道查看事实一致性
- 分析新闻来源的可靠性

---

## 模式决策树

```
用户输入
├── 一句话简短问题（"是不是真的""靠谱吗""真的假的"）
│   └── → 快速模式：Phase 1(简化) → Phase 3(搜2-3个信源) → Phase 5(一句话结论)
├── 要求详细分析（"核实这条新闻""帮我查一下""详细分析"）
│   └── → 完整模式：Phase 1→2→3→4→5 全流程
├── 提供截图/转发消息
│   └── → 完整模式 + 图片验证（Phase 3.3）
└── 批量核实（"这几条新闻都是真的吗"）
    └── → 逐条走完整模式，每条独立评级
```

---

## 核查工作流（5 步）

### Phase 1：信息提取与解构

**执行步骤（按顺序操作）：**

1. **逐句阅读**用户提供的新闻内容，不要跳读
2. **填写以下表格**（每项必须填写，不能留空，不确定的写"待验证"）：

| 要素 | 提取结果 | 验证优先级 |
|------|----------|-----------|
| **Who** — 涉及谁 | [具体人名/机构名] | 高/中/低 |
| **What** — 发生了什么事 | [一句话事实陈述] | 高 |
| **When** — 何时发生 | [具体日期或"近日"等模糊词] | 高 |
| **Where** — 何地发生 | [具体地点] | 中 |
| **Why** — 原因 | [文中给出的原因] | 中 |
| **How** — 怎么发生的 | [经过描述] | 低 |
| **来源媒体** | [发布媒体名称] | 高 |
| **核心数据** | [具体数字/金额/统计] | 高 |

3. **分离事实与观点**：用 `[事实]` 和 `[观点]` 标记新闻中的每句话
4. **判定新闻类型**：从以下类别中选择（决定 Phase 3.2 用哪套验证）：
   - 自然灾害 / 科学医学 / 经济金融 / 社会法治 / 国际事务 / 体育娱乐 / 其他
5. **生成搜索关键词**：从上表中提取 2-3 组搜索词：
   - 中文搜索：`核心事实 + 时间 + 地点`（如："日本核废水 太平洋 海鲜 2024"）
   - 英文搜索（涉及国际事件时）：`core fact + date + location`（如："Japan nuclear wastewater Pacific seafood 2024"）
   - 反向搜索：`核心事实 + 辟谣/谣言/fact check`

**输出**：上述完整表格 + 新闻类型 + 搜索关键词列表。

🔴 **CHECKPOINT：如果新闻内容信息严重不足（5W1H中3项以上为"待验证"且用户无法补充），直接跳到 Phase 5 输出"无法判定"评级，不进入后续验证。**

🔴 **CHECKPOINT：如果 Phase 2 红旗命中 ≥ 5 项（高度可疑），在进入 Phase 3 前先搜索辟谣平台；如果已确认被辟谣，直接跳到 Phase 5 输出"不可信"评级，省去完整验证流程。**

---

### Phase 2：信源评估

#### 2.1 媒体层级判断

| 层级 | 示例 | 可信度 |
|------|------|--------|
| **一级信源** | 政府官方发布、当事机构声明、一手数据（如 USGS、央视总台记者） | ⭐⭐⭐⭐⭐ |
| **二级信源** | 主流权威媒体报道（新华社、人民日报、路透社、AP、BBC） | ⭐⭐⭐⭐ |
| **三级信源** | 知名门户/财经媒体转载（财联社、澎湃、环球网） | ⭐⭐⭐ |
| **四级信源** | 地方媒体、行业媒体转载 | ⭐⭐ |
| **五级信源** | 自媒体、个人账号、来源不明 | ⭐ |

**操作**：根据新闻来源媒体，判定层级并记录。如果原始来源是五级信源，后续验证必须重点寻找二级以上信源佐证。

🔴 **CHECKPOINT：如果原始信源为五级（自媒体/个人账号）且红旗命中 ≥ 2 项 → 跳过 Phase 3 通用验证中的步骤2（多源搜索），直接进入步骤4（辟谣搜索），因为低质量信源的多源搜索往往只是同一谣言的不同转载。**

#### 2.2 红旗检查清单

逐项检查（每项必须勾选，不能跳过）：

- [ ] 标题使用耸动/夸张用语（"震惊！""太可怕了！""速转！"）
- [ ] 缺少记者署名或具体信源
- [ ] 使用"据说""网传""消息人士"等模糊措辞
- [ ] 催促转发（"赶紧转发""再不看就删了"）
- [ ] 只有截图没有链接
- [ ] 时间地点人物等关键信息模糊（"某地""某人""近日"）
- [ ] 文中插入过多广告或引导关注
- [ ] 内容有明显逻辑矛盾
- [ ] 存在旧闻翻新（用过去的事件配上新日期）

**红旗命中 ≥ 3 项** → 核实结论上限为"存疑"，不能直接判"可信"。

---

### Phase 3：多源交叉验证

#### 3.1 通用验证（必须执行）

**搜索参数速查：**

| 信源 | 搜索命令格式 | 示例 |
|------|------------|------|
| 新华社 | `site:xinhuanet.com 核心事实` | `site:xinhuanet.com 日本核废水 太平洋` |
| 央视新闻 | `site:cctv.com 核心事实` | `site:cctv.com 地震 四川` |
| 人民日报 | `site:people.com.cn 核心事实` | `site:people.com.cn 新能源汽车 出口` |
| 辟谣平台 | `site:piyao.org.cn 关键词` | `site:piyao.org.cn 喝热水致癌` |
| Reuters | `site:reuters.com fact check 核心事实` | `site:reuters.com fact check Japan wastewater` |

**搜索策略（按顺序执行，每步记录结果）：**

1. **中文权威信源搜索**（必须）
   - 搜索词：Phase 1 生成的中文关键词
   - 重点查看：新华社、人民日报、央视新闻是否有报道
   - 记录：找到的报道数量、核心事实是否一致

2. **中文多源搜索**（必须）
   - 搜索词：核心事实 + 不同表述方式
   - 重点查看：澎湃、财联社、环球网等三级以上信源
   - 记录：各报道之间的差异点

3. **英文信源搜索**（涉及国际事件时必须）
   - 搜索词：Phase 1 生成的英文关键词
   - 重点查看：Reuters、AP、BBC、NYT
   - 记录：中外媒体报道是否一致

4. **辟谣平台搜索**（必须）
   - 搜索词：核心事实 + "辟谣" 或 "谣言" 或 "fact check"
   - 查看：中国互联网联合辟谣平台、微博辟谣、Snopes、FactCheck.org
   - 记录：是否已被辟谣

🔴 **CHECKPOINT：如果中文权威信源（步骤1）和辟谣平台（步骤4）均无结果，且原始信源为四/五级 → 核实结论上限为"存疑"。**

🔴 **CHECKPOINT：如果 Phase 3 搜索发现 ≥ 3 个信源但核心数据相互矛盾（如A说100人伤亡、B说10人） → 不要强行判定，评级降为"存疑"，在报告中列出各信源数据差异。**

#### 3.2 分类别专项验证（根据 Phase 1 判定的新闻类型执行对应项）

**自然灾害类**（地震、台风、洪水等）：
- 地震 → 必须查 USGS (earthquake.usgs.gov) + 中国地震台网
- 台风 → 必须查中央气象台 + JTWC
- 如果查不到对应记录 → 核实结论为"不可信"

**科学/医学类**：
- 必须查 PubMed 或 WHO 官网是否有相关研究
- 必须核实文中提到的专家/机构是否真实存在
- 如果专家/机构不存在 → 核实结论为"不可信"

**经济/金融类**：
- 必须查证交所/深交所公告（涉及上市公司时）
- 必须查央行/统计局官网（涉及宏观经济数据时）
- 必须查天眼查/企查查（涉及企业信息时）

**社会/法治类**：
- 必须查公安/法院官方通报
- 必须查当地政府官方公众号
- 如果涉及具体案件但无官方通报 → 核实结论上限为"存疑"

**国际事务类**：
- 必须查涉事国家官方声明
- 必须对比中外媒体报道差异
- 必须查联合国等国际组织声明（如适用）

**体育/娱乐类**：
- 必须查当事方官方社交媒体/经纪公司声明
- 必须查赛事官方结果（体育类）
- 如果仅为八卦无官方确认 → 核实结论上限为"存疑"

#### 3.3 图片/视频验证（用户提供图片/视频时必须执行）

- 使用搜索引擎"以图搜图"检查图片是否被移花接木
- 注意图片中的文字、路牌、车牌等细节是否与声称的地点一致
- 检查 EXIF 信息（如有原图）
- 如果图片被证实为旧图/移花接木 → 核实结论为"不可信"

### Phase 4：信息比对与矛盾分析

将 Phase 2 和 Phase 3 收集的信息进行系统比对：

| 比对维度 | 各信源描述 | 是否一致 | 差异分析 |
|----------|-----------|---------|---------|
| 核心事实 | [信源A/B/C各自说法] | ✅/❌ | [差异原因] |
| 关键数据 | [各信源数据] | ✅/❌ | [差异原因] |
| 时间线 | [各信源时间] | ✅/❌ | [差异原因] |
| 权威确认 | [是否有权威机构确认] | ✅/❌/无 | — |
| 官方辟谣 | [是否被辟谣] | 是/否 | — |

**差异判定规则：**
- **正常差异**：不同机构的测量标准、四舍五入、时区换算 → 不影响评级
- **异常差异**：核心事实相互矛盾（如A说发生B说没发生）→ 降级为"存疑"或"不可信"

**评级决策树（按优先级从高到低判断）：**

```
是否被权威机构辟谣？
├── 是 → 🔴 不可信
└── 否 → 核心事实是否有 ≥ 2 个独立权威信源确认？
    ├── 是 → 各信源数据是否一致？
    │   ├── 是 → 🟢 可信
    │   └── 否（正常差异）→ 🟡 部分可信
    │   └── 否（异常差异）→ 🟠 存疑
    └── 否 → 是否有 ≥ 1 个三级以上信源报道？
        ├── 是 → 🟠 存疑
        └── 否 → 是否有信源报道但全部为四/五级？
            ├── 是 → 🟠 存疑
            └── 否（完全无报道）→ ⚪ 无法判定
```

🔴 **CHECKPOINT：如果 Phase 4 比对发现核心事实存在异常差异（≥ 2个权威信源说法矛盾） → 评级不超过"存疑"，不要选择性采信某一方。在报告中并列展示各信源说法，让用户自行判断。**

### Phase 5：输出核实报告

#### 可信度评级标准

| 评级 | 含义 | 条件 |
|------|------|------|
| 🟢 **可信** | 新闻基本属实 | 多个独立权威信源确认，核心事实一致，信息链完整可追溯 |
| 🟡 **部分可信** | 核心事实属实但部分细节有误或夸大 | 核心事实可验证，但部分细节无法确认或有偏差 |
| 🟠 **存疑** | 无法充分验证 | 仅有少数信源，无权威确认，关键信息模糊 |
| 🔴 **不可信/谣言** | 确认为虚假信息 | 被权威机构辟谣，或核心事实与权威数据严重矛盾 |
| ⚪ **无法判定** | 证据不足 | 信息过少无法做出判断，建议持续关注 |

#### 报告模板

```markdown
## 新闻核实报告

### 📰 新闻摘要
- **标题**：[新闻标题或核心主张]
- **来源**：[发布媒体] / [发布时间]
- **核心主张**：[一句话概括]
- **新闻类型**：[自然灾害/科学医学/经济金融/社会法治/国际事务/体育娱乐/其他]

### ✅ 核实结论：[评级emoji] [评级] — [一句话结论]

### 📊 核实依据

| 维度 | 结果 | 详情 |
|------|------|------|
| 原始信源层级 | ⭐~⭐⭐⭐⭐⭐ | [媒体名称及层级] |
| 权威信源确认 | ✅/❌ | [哪些权威媒体有/无报道] |
| 多源一致性 | ✅/⚠️/❌ | [各信源是否一致] |
| 数据核实 | ✅/⚠️/❌ | [数字/金额是否匹配] |
| 辟谣平台 | ✅未收录/❌已辟谣 | [哪个平台] |
| 红旗项 | [数量]项 | [列出命中项] |

### 🔍 信源清单
| # | 媒体 | 层级 | 报道要点 | 链接 |
|---|------|------|---------|------|
| 1 | [媒体名] | [层级] | [要点] | [URL] |

### ⚠️ 注意事项
[差异说明、需要持续关注的点]

### 💡 建议
[是否可转发、是否需等待更多信息]
```

## 完整示例

**用户输入**："日本排放核废水后，太平洋海鲜已经不能吃了"

**Phase 1 输出**：

| 要素 | 提取结果 | 验证优先级 |
|------|----------|-----------|
| Who | 日本政府 / 东京电力 | 高 |
| What | 排放核废水导致太平洋海鲜不可食用 | 高 |
| When | 2023年8月起（持续至今） | 高 |
| Where | 太平洋 | 中 |
| Why | 福岛核电站处理水排海 | 中 |
| 来源 | 用户口述，未提供具体来源 | 高 |
| 核心数据 | 无具体数据 | 高 |

- 新闻类型：科学/环境
- 搜索关键词：`日本核废水 太平洋 海鲜 安全` / `Japan nuclear wastewater Pacific seafood safety` / `核废水 海鲜 辟谣`

**Phase 2**：原始信源 = 用户口述（五级），红旗 = 2项（无来源、关键数据模糊）

**Phase 3**：
- 权威信源：新华社有多篇报道，IAEA发布评估报告称排放符合国际安全标准
- 辟谣平台：中国互联网联合辟谣平台有相关澄清
- 科学验证：WHO、IAEA均有公开数据，各国食品安全机构有监测数据

**Phase 4**：核心事实存在夸大 — 核废水排放属实，但"不能吃了"是过度推断，权威机构评估为安全可控

**Phase 5 评级**：🟡 部分可信 — 核废水排放属实，但"太平洋海鲜不能吃了"是夸大表述

## 核查原则

1. **客观中立**：只陈述事实和证据，不加入主观判断
2. **区分事实与观点**：分清"发生了什么"和"怎么评价"
3. **承认局限**：无法确认时坦诚告知，不强行下结论
4. **解释差异**：不同信源的合理差异应给出解释
5. **时效提醒**：标注核实时间，提醒后续可能有更新
6. **不传播谣言**：确认为谣言时，提醒用户不要转发

## 反例与黑名单（不要做什么）

| # | 反模式 | 为什么不要做 | 正确做法 |
|---|--------|------------|---------|
| 1 | **只搜一个信源就下结论** | 单信源不可靠，可能被误导 | 必须至少搜 2 个独立信源交叉验证 |
| 2 | **把自媒体当权威信源** | 自媒体可信度低（⭐），不能作为主要依据 | 以一级/二级信源为主，自媒体只能作为线索 |
| 3 | **忽略辟谣平台直接判可信** | 可能已被辟谣但你没查 | Phase 3 步骤4 辟谣搜索必须执行 |
| 4 | **把"部分可信"说成"可信"** | 夸大可信度会误导用户 | 有瑕疵必须标"部分可信"，如实说明哪些部分有偏差 |
| 5 | **省略报告模板中的章节** | 用户需要完整信息做判断 | 报告模板所有章节必须填写，无内容写"无" |
| 6 | **用"据报道""据悉"作为核实依据** | 这不是核实，是转述 | 核实必须有具体信源名称和链接 |
| 7 | **不区分事实和观点** | 观点不能被"核实"为事实 | 明确标记[事实]和[观点]，只核实事实部分 |
| 8 | **图片不验证直接采信** | 图片可能被移花接木或PS | 涉及图片时必须做以图搜图验证 |
| 9 | **搜索无结果就判"不可信"** | 搜不到≠不存在，可能是搜索策略问题 | 搜不到时判"存疑"或"无法判定"，说明搜索局限 |
| 10 | **跳过快速模式判断直接跑全流程** | 浪费时间，用户可能只需要一句话结论 | 先判断场景，简短问题用快速模式 |
| 11 | **选择性采信对自己有利的信源** | 确认偏差会扭曲结论 | 必须同等对待所有信源，矛盾时并列展示 |
| 12 | **忽略时间线差异** | 旧闻翻新是常见谣言手法 | 必须核实事件发生日期与报道日期是否匹配 |
| 13 | **对科学/医学类新闻不查学术来源** | 非专业媒体可能误读科学结论 | 必须查原始论文或权威机构声明 |

## 失败处理

| 场景 | 触发条件 | 处理动作 |
|------|---------|---------|
| web_search 无结果 | 搜索返回空或无关结果 | 换关键词重试一次；仍无结果则记录"搜索未找到相关信源"，评级上限为"存疑" |
| 信源相互矛盾 | 2个以上权威信源说法不一 | 列出各信源说法，评级降为"存疑"，标注矛盾点 |
| 用户提供的新闻信息不完整 | 缺少来源/时间/地点等关键信息 | 先问用户补充；用户无法补充则走快速模式，评级上限为"存疑" |
| 无法访问权威网站 | USGS/WHO等网站无法访问 | 记录"该信源暂不可访问"，用其他信源替代，评级扣分 |
| 新闻涉及未公开事件 | 所有信源都无相关报道 | 不判"不可信"，判"无法判定"，建议持续关注 |
| 用户要求核实图片但无原图 | 只有截图没有原图 | 仍做以图搜图，但标注"图片验证受限"，评级扣分 |
| 搜索结果全是同一来源转载 | 表面多源实际单源 | 标注"疑似单一信源扩散"，评级上限为"存疑" |
| 用户要求核实的新闻涉及自身利益 | 用户可能是当事方 | 保持客观，不因用户立场倾斜评级；注明"用户可能与事件相关" |
| 新闻为旧闻翻新 | 搜索发现原始事件日期与声称不符 | 判为"不可信"，在报告中注明原始事件日期 |
| 新闻涉及专业领域（法律/医学/金融） | 需要专业知识判断 | 不自行解读专业结论，引用权威机构的官方解读，注明"专业领域，建议咨询专业人士" |
| 新闻为突发事件/正在发展中 | 信息持续更新，各阶段报道可能不一致 | 评级标注"⚠️ 事件发展中"，提醒用户关注后续更新，不以早期报道定性 |
| 用户提供的是外文新闻 | 语言障碍影响验证 | 先翻译核心事实，再用中英文分别搜索验证，注明翻译可能引入的偏差 |
